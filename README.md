# 缓一缓

> 它会过去。

惊恐发作时，人很难读完一大段说明，也不适合做复杂选择。缓一缓把这几分钟拆成一组简单的步骤，一次只做一件事。

[打开网页版](https://shoot5313.github.io/anding-card/)

## 怎么使用

- 如果此刻很难受，先选出最抢注意力的感受。接下来只需回答几个短问题，再按住圆圈呼吸、找身边的东西、记住几扇窗亮起的顺序，或慢慢擦开一幅图景。
- 如果现在状态还好，可以读一张短知识卡、练习观察一个普通感觉、回看刚才发生了什么，也可以为下一次准备自己的卡片。
- 卡片可以保存到相册或设成锁屏。下次不必寻找工具，打开相册就能看到。

工具不要求登录，也不会把你填写的内容发到服务器。草稿只留在当前浏览器中。

## 使用边界

缓一缓是自助放松工具，不能代替医生或心理咨询师。如果是第一次出现这些症状，或这次的感受与以往不同，请先就医排除身体原因。情况紧急时，请拨打 120 或 110。

如果发作频繁，已经影响到生活，可以联系专业人员，或拨打 12356 全国统一心理援助热线。各地服务时间可能不同。

项目中的健康信息来源见 [SOURCES.md](./SOURCES.md)。

## 本地运行

```bash
npm run serve:web
```

浏览器打开 `http://localhost:4317`。

## 构建与部署

```bash
npm run build:web
```

网页版会生成在 `site/`，可以部署到任意静态托管服务。推送到 `main` 分支后，仓库内的 GitHub Actions 会自动更新 GitHub Pages。

生成小红书上传包：

```bash
npm run release
```
