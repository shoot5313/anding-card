# 安定卡 · 它会过

一个给熟悉的惊恐反应准备的离线自助放松小工具：发作时一次只做一件事，状态好时写一张存在相册里的安定卡。

它不诊断、不治疗，也不替代医生或心理咨询师。第一次出现，或这次症状与以往不同，应先及时就医排除身体原因。

## v0.1 已有内容

- 6 屏急救流程：面对、接受、轻缓呼吸、54321 落地、正计时陪伴、给自己的话。
- 每一屏只有一个主要动作，可随时跳过，或直接去看给自己的话。
- 平静时填写锚点、安全场景、三句话和行动清单。
- 本地 Canvas 生成 1080 × 1920 PNG；小红书容器内通过官方桥接保存到相册。
- 简短了解页、每页可见的使用边界、12356 真人帮助入口。
- 无账号、无网络请求、无统计、无广告；`localStorage` 只缓存准备页草稿，丢失不影响急救流程。

## 已定下的 7 个产品选择

1. 主名：**安定卡**；副标题：**它会过**。
2. 默认三句话：
   - 怕也没关系，不用把它赶走。
   - 这些感觉很难受，但感觉不是命令。
   - 先把这一分钟交给时间；下一分钟来了，再过下一分钟。
3. 卡片底句：**平静不是假的；它一直是我身上的另一种可能。**
4. 示例锚点与场景：窗台上的绿萝；靠窗的沙发、微凉的空气、雨落在遮雨棚上的声音。
5. 四本书的一句话已写进“了解”页，定位为陪读提示，不作治疗推荐。
6. 真人热线使用 **12356 全国统一心理援助热线**；各地服务时段可能不同。
7. v0.1 不放“分享给信任的人”按钮。小工具的发布接口会进入公开笔记流程，不适合冒险误分享；保存后可从系统相册私下发送。

## 文案与医学边界

初稿里“峰值通常在十分钟前后”“十分钟后它开始退了”等句子被改成不承诺个人时程的表达。公开资料显示，惊恐发作可能持续几分钟到一小时或更久；因此计时只陈述过去了多久，不把十分钟做成隐形倒计时。

呼吸页写成“不要吸很深，轻轻跟着”，避免让用户为了做对节奏而强迫呼吸。紧急或与以往不同的身体症状，仍明确引导 110 / 120 或急诊。

## 本地运行

```bash
npm run serve
```

打开 `http://localhost:4317`。页面本身也可以直接以 `file://` 离线打开。

## 网页版与添加到主屏幕

网页版与小红书版共用 `styles.css` 和 `src/app.js`。Web 构建只在生成的 `site/` 中加入 manifest、Service Worker、离线缓存和“放到手机桌面”入口，不会污染小红书上传包。

```bash
npm run serve:web
```

然后打开 `http://localhost:4317`。部署到 GitHub Pages 后的预定地址是：

`https://shoot5313.github.io/anding-card/`

`.github/workflows/pages.yml` 会在 `main` 分支更新时验证共享运行时、构建 `site/`，再部署 Pages。当前目录没有有效 Git 仓库；首次发布仍需创建 `shoot5313/anding-card` 并推送。

需要交给其他静态托管平台时，可生成独立网页包：

```bash
npm run release:web
```

产物是 `dist/anding-card-web-v0.1.0.zip`，解压后把全部文件放在同一站点目录即可。

## 小红书上传包

```bash
npm run release
```

产物：

- `dist/anding-card-v0.1.0.zip`：上传包，根目录只有一个 `index.html`。
- `dist/anding-card-icon-1024.png`：平台图标。
- `dist/artifact.json`：包大小、SHA-256、图标哈希和文件数。

构建会先跑静态门禁，再生成固定时间戳、可复现的 ZIP，并检查 10 MiB 上限、允许类型、安全路径和根入口。
