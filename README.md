# 缓一缓

> 它会过去。

惊恐发作时，长说明看不进去，选项一多也累。缓一缓只管眼前这几分钟。屏幕一次问一件事，你能走到哪里，就先走到哪里。

[打开网页版](https://shoot5313.github.io/anding-card/)

## 怎么使用

- 此刻很难受：先点出最抢注意力的感受。工具会问几个短问题，再陪你呼吸、做六个找东西的小任务，或做一个安静的小活动。每一页都可以直接退出。
- 想让注意力忙一点：可以玩亮窗记忆、擦开图景，或从 100 个小抽屉里抽一道冷知识。答题不计分，答完就看解释。
- 现在状态还好：读一点笔记，跟着叶子练舒适呼气、陪机器人松开手掌，或让小蜜蜂带着轻哼走一小段。也可以回看一次发作，准备自己的卡片。
- 想给下次留句话：把卡片存进相册或设成锁屏。下次翻开就能看到。

这里没有账户。填写的内容和看过的题目编号只留在当前浏览器中，不会发到服务器。

## 使用边界

缓一缓提供自助放松。诊断与治疗请交给医生和心理咨询师。第一次出现这些症状，或这次的感受与以往不同，请先就医排除身体原因。情况紧急时，请拨打 120 或 110。

如果发作频繁，已经影响到生活，可以联系专业人员，或拨打 12356 全国统一心理援助热线。各地服务时间可能不同。

## 本地运行

```bash
npm run serve:web
```

浏览器打开 `http://localhost:4317`。

## 构建与部署

```bash
npm run build:web
```

网页版会生成在 `site/`，可以部署到任意静态托管服务。推送到 `main` 分支后，仓库内的 GitHub Actions 会自动更新 GitHub Pages。

生成小红书上传包：

```bash
npm run release
```
